# Documentación General

Este repositorio alberga la **Documentación General** sobre tus principales áreas de interés:

- 🚢 **Docker** (conceptos, N8N, RabbitMQ…)  
- 💻 **Programación** (Patrón Repository, ejemplos y buenas prácticas)  
- 🖥️ **Servidores & DevOps** (Linux, Nginx, Docker Compose…)  
- 🔬 **Investigación** (metodologías, referencias)  
- 📦 **Recursos** (cheatsheets, snippets, plantillas)

Construido con [Docsify](https://docsify.js.org/) y potenciado por el tema [docsify-themeable](https://github.com/jhildenbiddle/docsify-themeable).

---

## Contenido

- **Docker**  
  - `/docs/docker/index.md` → Página de inicio de la sección  
  - `/docs/docker/concept.md` → Conceptos básicos  
  - `/docs/docker/n8n.md`     → Instalación y configuración de n8n en Docker  


- **Otros**  
  - `coverpage.md`     → Portada personalizada  
  - `introduction.md`  → Introducción general  
  - `sidebar.md`       → Menú lateral global  
  - `navbar.md`        → Barra de navegación (opcional)
